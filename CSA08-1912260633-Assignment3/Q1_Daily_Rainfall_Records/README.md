# Q1 – Lists and Slicing: Daily Rainfall Records
Run: `python task01.py` (run from this folder or use the path to the script).
Input: `rainfall.csv` contains 365 daily rainfall readings in millimetres.
Result: weekly totals, wettest/driest week, daily extrema, dry-day list, 7-day moving average, edge-case tests and a timing comparison are printed.
